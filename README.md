## 上傳檔案
git status
確認哪些檔案被修改。

git add backend/app.py
告訴 Git 要提交這支 Python 程式。

git commit -m "Update Python code"
記錄這一次的修改。

git push origin main
將本機已提交的修改上傳到 GitHub。
